# Week3-Mini-Project-sql
# SQL Fitness and Activity Database

This repository contains the SQL code for my Week 3 Mini Project in Analytics and AI for Health Strategies.

## Project Overview

This project creates a small fitness and activity database using SQL. The database includes three related tables:

- `users`
- `activities`
- `workouts`

The SQL file includes table creation, sample data, analysis queries, and basic query optimization using indexes.

## What the SQL File Includes

- Creates relational tables for users, activities, and workouts
- Inserts sample user, activity, and workout data
- Summarizes user demographics
- Calculates total activities and calories burned
- Identifies popular activity types
- Summarizes workout counts and intensity
- Finds top performers by calories burned
- Adds indexes to improve query performance
